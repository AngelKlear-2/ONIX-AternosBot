# Changelog

## [1.2.0] — 2026-05-14

### Исправления стабильности

- **CRITICAL** Исправлена гонка двойного переподключения: `handleDisconnect` и `handleError` оба могли вызвать `connect()` одновременно — добавлен флаг `reconnecting`.
- **CRITICAL** При обнаружении дубликата бота (409 Conflict) процесс теперь завершается через `process.exit(1)` вместо молчаливого зависания.
- **CRITICAL** Метка времени auth-cooldown перенесена внутрь `try`-блока — ошибка в `bot.chat()` больше не блокирует авторизацию на 15 секунд.
- **HIGH** `statusTimer` теперь останавливается при разрыве соединения и запускается только после успешного логина.
- **HIGH** Добавлен `instanceId` для защиты от устаревших reconnect-таймаутов при быстром stop/start.
- **HIGH** `sendMessage` обёрнут в try/catch — ошибки Telegram больше не приводят к необработанным rejection'ам.
- **HIGH** Добавлены глобальные обработчики `uncaughtException` и `unhandledRejection` в `bot.js`.
- **MEDIUM** Добавлен флаг `menuUpdating` — параллельные вызовы `refreshMainMenu` больше не создают дублей сообщений.
- **MEDIUM** Обработчик `polling_error` теперь реагирует на HTTP 429 (пауза 30 сек) и сетевые ошибки (ETIMEDOUT, ECONNRESET).
- **MEDIUM** Добавлена валидация `MC_HOST` как обязательного поля; предупреждение при пустом `MC_REGISTER_PASS` с активной авторизацией.
- **LOW** `shutdown()` сделан async с таймаутом 5 сек на `bot.stopPolling()`.
- **LOW** Запись `.env` теперь атомарная (write-tmp + rename).
- **CRITICAL** `stop()` усилен: `removeAllListeners()` + `_client.end()` + отложенный `socket.destroy()` — игрок надёжно пропадает с сервера.

### Новые возможности

- **Настройки сервера через Telegram:** в меню «⚙️ Настройки» появились кнопки для изменения адреса сервера, порта и версии Minecraft без редактирования `.env` вручную.
- **Флаг `closing`:** при нажатии «Отключить» повторный старт блокируется на ~5 сек, пока сокет не закрыт — устраняет накопление «призраков» при частом переподключении.
- **Реалистичные случайные ники:** заменены шаблоны `Player_1234` / `Bot_42` на комбинации реальных имён, игровых слов и суффиксов (Andrew42, ShadowHunter, xXViperXx и т.п.).
- **Улучшено отображение в меню:** режим RANDOM теперь показывает активный ник (`🎲 случайный → CurrentNick`), расшифрованы режимы авторизации, добавлены разделители и иконки.
